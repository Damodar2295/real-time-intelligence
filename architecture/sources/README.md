# Source evidence

This directory contains architecture-relevant meeting extracts, direct user decisions and historical structured models. Original JPEG/JPG reference images and external role-brief attachments are not committed.

Source paths beginning with `architecture&implementation plan/`, `design&planning/`, or `reranker based signal detection piepline/` in the JSON records identify external input evidence, not repository files. Their names and source IDs are retained to preserve traceability. Refer to [source traceability](../source-traceability.md) for the extracted assertions.
